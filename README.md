## ⚡ Overview

This repository houses the source code for my personal software engineering portfolio. The design is inspired by high-contrast editorial dark typography (`#050505` obsidian with `#FF4522` fiery vermilion accents), fluid micro-interactions, and real-time multiplayer Figma-style cursor badges.

### 🌟 Key Highlights
- **100vh Full-Bleed Desktop Layout:** Massive condensed `"PORTFOLIO"` display typography, centered monochrome tailored portrait, and interactive cursor physics.
- **Full Mobile Responsiveness:** Clean vertical stacked layout on phone and tablet viewports with a glassmorphic dropdown navigation drawer and large touch targets (`min-h-[46px]`).
- **Cinematic Case Study Modals:** Framer Motion shared `layoutId` card morphing transitions for deep-dive architectural breakdowns.
- **Reliable Direct Dispatch:** Direct 1-click webmail integration with pre-filled Gmail Compose and native mail client fallbacks.

## 🚀 Local Development Setup

To run this portfolio locally on your machine:

### Prerequisites
- Node.js (v18.0.0 or higher)
- npm or yarn

### Installation
```bash
# 1. Clone the repository
git clone https://github.com/praveenvedha26/portfolio.git

# 2. Navigate to project root
cd portfolio

# 3. Install project dependencies
npm install

# 4. Start local Vite development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to view the application with Hot Module Replacement (HMR).

### Production Build
```bash
# Build the optimized production bundle
npm run build

# Preview the production build locally
npm run preview
```
